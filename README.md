## 🧠 2. AI, Machine Learning & Deep Learning

### 📊 WaferVision AI — Semiconductor Wafer Defect Classification

**Repository:** [wafer-defect-detection-ai](https://github.com/kadarkarai474/wafer-defect-detection-ai)

A deep learning solution for automated semiconductor wafer defect classification using EfficientNetB0 and transfer learning.

**Key work:**

* WM-811K wafer map defect classification
* TensorFlow and Keras
* EfficientNetB0 transfer learning
* Dataset preprocessing
* Two-phase model training
* Fine-tuning and checkpoint management
* GPU acceleration using CUDA
* Single-image prediction
* Confidence scores and Top-3 predictions
* Model evaluation and training history

### 🖼️ JARVIS — Deep Learning Image Restoration

**Repository:** [JARVIS](https://github.com/kadarkarai474/JARVIS)

A deep learning research framework for blind image restoration and 2× super-resolution using the Restormer architecture.

**Key work:**

* Degraded grayscale image restoration
* Noise and blur analysis
* Restormer-based image restoration
* 128 × 128 to 256 × 256 super-resolution
* Modular CNN / Transformer research framework
* Dataset and inference pipeline
* PSNR, SSIM and LPIPS evaluation
* GPU-based training and inference workflows
