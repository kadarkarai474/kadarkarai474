## 🚀 Featured Engineering Projects

### 🤖 01. Smart Four-Wheel Controller

**Embedded Systems | Robotics | PCB Design**

An ESP32-based robotic controller integrating motor control, sensors, display, and wireless communication.

* ESP32 32-pin development platform
* L298N motor driver and four-wheel control
* HC-SR04 ultrasonic sensor
* MPU6050 motion sensor
* OLED display interface
* Wi-Fi and Bluetooth connectivity
* 12 V input with buck-converter power management
* Buzzer, status indicators, and motor connectors

### 🔌 02. ESP32 Custom PCB

**Microcontroller Hardware | PCB Development**

A custom ESP32-based PCB design involving schematic development, component integration, footprint assignment, PCB layout, and 3D verification.

### ⚙️ 03. STM32 Base Design

**Embedded Hardware | Multi-Interface Controller**

A custom STM32-based controller board developed through PCB design work using the eSim/KiCad workflow.

* USB connectivity
* UART communication
* SPI interface
* CAN interface
* PWM outputs
* Analog and digital I/O
* Four-layer PCB architecture

### 🧩 04. AT89S51 USB-C Multi-Interface Development Board

**8051 Microcontrollers | Hardware Design**

A custom development board built around the AT89S51 microcontroller, incorporating USB-C connectivity and multiple hardware interfaces.
